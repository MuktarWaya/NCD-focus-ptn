# Goal
เพิ่มหน้าติดตามความครบของข้อมูลรอบเริ่มต้น W0 ในระบบเดิม ให้ดูภาระงานคณะทำงาน จำนวนรายบุคคลที่ครบ/บางส่วน/ยังไม่มี และหัวข้อที่ขาด กรองรายชุมชนและจัดมุมมองสำหรับแคปภาพส่งได้

# Brainstorm / evidence
- ผู้ใช้ยืนยัน W0 ในงานร่างข้อความก่อนหน้า
- หน้า worker progress เดิมนับจำนวนที่ติดตามแล้ว ไม่ตรวจความครบของช่องในแบบส่งหน่วยจัดการ ต้องมีหน้าความครบที่แสดงนิยามชัด
- มีข้อมูลดิบ state.quarterlyExportData ซึ่งรักษาช่องว่างได้ ไม่ควรใช้ state.quarterlyData ที่แปลงช่องว่างเป็นศูนย์เพื่อแสดงกราฟ
- การตรวจเวลา 11:05 น. พบ 167 คน มี W0 85 คน และช่องพฤติกรรมที่เพิ่งเพิ่มยังไม่มีข้อมูล; 76 คนไม่มีผลติดตามเลย และ 6 คนมี M0 ที่ต้องตรวจรอบก่อนกรอกซ้ำ
- บางชื่อผู้รับผิดชอบไม่ตรง directory ต้องขึ้นข้อสังเกตให้ผู้ประสานงานตรวจ ไม่รวมชื่อคล้ายกันหรือย้ายคนให้เอง

# Proposed view
เพิ่มเมนู “ติดตามข้อมูล W0” แยกจากทะเบียนรหัสสีสุขภาพ เพื่อให้สถานะการกรอกข้อมูลกับสีปิงปองสุขภาพมีความหมายชัดเจน

ส่วนบนแสดงชุมชนที่เลือก รอบ W0 และเวลาที่อ่านข้อมูลล่าสุด ตามด้วยตัวกรองชุมชน คณะทำงาน และสถานะความครบ

สรุปยอดเป็นจำนวนรายบุคคลในขอบเขตที่เลือก: รับผิดชอบทั้งหมด / ครบ / บางส่วน / ยังไม่มี

ตารางต่อคณะทำงาน: ชื่อ, รับผิดชอบกี่คน, เขียวกี่คน, เหลืองกี่คน, แดงกี่คน, รายการที่ขาดพร้อมจำนวนคน คลิกแสดงรายละเอียดหรือคัดลอกข้อความได้

ปุ่ม “โหมดแคปหน้าจอ” ซ่อนเมนูและรายละเอียดที่ไม่จำเป็น ให้เหลือหัวรายงาน ชุมชน เวลา นิยามสี และรายการคณะทำงาน ไม่มีช่องตารางที่เลื่อนภายในจนซ่อนแถว ใช้ปุ่มกลับมุมมองปกติได้ บนมือถือแสดงเป็นรายการที่อ่านง่ายไม่ต้องเลื่อนแนวนอน

# Color rules
ใช้สถานะรายบุคคลก่อนรวมรายคณะทำงาน คนหนึ่งนับเพียงสีเดียว
- เขียว “ครบตามแบบ W0”: มีผล W0 และข้อมูลที่ต้องใช้ตามแบบของกลุ่มเสี่ยง/กลุ่มป่วยครบ ไม่มีค่าที่ต้องตรวจความถูกต้องก่อนรายงาน
- เหลือง “มีบางส่วน”: มีผล W0 แต่ขาดข้อมูล/มีค่าต้องตรวจ หรือมีผลรอบอื่น/ข้อมูลเดิม M0 ที่ต้องตรวจให้ตรง W0 ขึ้นข้อความ M0 แยก ไม่คัดลอกผลข้ามรอบเอง
- แดง “ยังไม่มีผลติดตาม”: ไม่พบผลติดตามของบุคคลนั้นเลย มีชื่อในทะเบียนอย่างเดียวไม่ถือว่ามีผลประเมินแล้ว

สำหรับสีภาพรวมของคณะทำงาน: เขียวเมื่อทุกคนเขียว, แดงเมื่อทุกคนแดง, เหลืองเมื่อมีข้อมูลบางส่วนหรือคละสถานะ ใช้ตัวเลขแยกทั้งสามสีทุกครั้ง เพื่อไม่ซ่อนคนสีแดงในกลุ่มภาพรวมเหลือง

คณะทำงานที่ไม่มีคนรับผิดชอบไม่ให้ขึ้นเขียวจากจำนวนศูนย์; ไม่แสดงแถวว่างในค่าเริ่มต้น

# Completeness rules
- ใช้ช่องตามแบบ Excel สำหรับแต่ละประเภท: กลุ่มเสี่ยงมีบ้านเลขที่และประเภทความเสี่ยง; กลุ่มป่วยมีโรค โรคร่วม ปีที่ป่วย ยาและผลแล็บ W0
- พฤติกรรม 9 รายการที่ใช้ส่งออก และค่าตรวจตามแบบต้องครบ; หมายเหตุไม่เป็นเงื่อนไขบังคับ
- ไม่เพิ่มเงื่อนไขจากคอลัมน์ที่ไม่อยู่ในแบบ เช่น มีประเภทกิจกรรมชัดแล้วไม่บังคับนาทีตัวเลขใหม่ ชั่วโมงนอนจริงไม่แทนการเลือกช่องในแบบที่นิยามยังซ้อนกัน
- “ไม่มี” ที่ผู้ประเมินบันทึกตรงกับความจริงเป็นข้อมูล ส่วนช่องว่างคือยังไม่มีข้อมูล
- ศูนย์นาทีออกกำลังกาย/ศูนย์ส่วนผักผลไม้เป็นค่าที่รับได้ ผลตรวจที่เป็นศูนย์หรือรูปแบบไม่ชัดให้ขึ้น “ต้องตรวจต้นทาง” ไม่สรุปว่าเป็นช่องว่างหรือไม่มีอาการ
- ผลแล็บที่ยังไม่มีกำหนดให้แจ้งสถานะ ไม่ชี้นำให้กรอกค่าหรือสั่งตรวจใหม่เพื่อให้เขียว
- หัวข้อข้อมูลที่ขาดนับเฉพาะคนที่มีผลรอบนั้นแล้ว และแยกคนที่ยังไม่มีผลทั้งรอบ เพื่อไม่รายงานซ้ำเป็นหลายคน
- เลขจำนวนต่อหัวข้ออาจนับบุคคลเดียวกัน; มีคำชี้แจงว่าไม่ให้บวกทุกหัวข้อเป็นจำนวนคนทั้งหมด
- สถานะชื่อผู้รับผิดชอบไม่ตรง directory/ยังไม่ระบุขึ้นข้อความให้ผู้ประสานงานตรวจ ไม่แก้ assignment ในขั้นวิเคราะห์
- สีแสดงความครบของข้อมูล ไม่ใช่ผลวินิจฉัยหรือระดับความเสี่ยงทางสุขภาพ

# Risks & mitigations
- พฤติกรรมเพิ่งเปิดเก็บทำให้ข้อมูลเดิมเป็นเหลือง: แสดงข้อความว่าบางช่องเพิ่งเพิ่ม ไม่สื่อว่าคณะทำงานไม่ได้ทำงานทั้งหมด
- M0 เข้าเกณฑ์เหลืองพร้อมข้อสังเกต: ไม่ทิ้งข้อมูลเก่า ไม่ทำให้เข้าใจว่าต้องกรอกซ้ำโดยอัตโนมัติ
- การกรองสีรายคนกับรายคณะทำงานอาจสับสน: ตัวกรองหลักเป็น “สถานะภาพรวมคณะทำงาน” และแสดงตัวเลขคนทั้งสามสถานะของทุกแถวที่เข้าเกณฑ์ ไม่เปลี่ยนตัวหารผู้รับผิดชอบเมื่อกรองสี
- สีสุขภาพเดิมกับสีความครบ: ใช้ชื่อ “ความครบ W0” และ legend ชัด ไม่ใช้กติกาปิงปองมาคำนวณความครบ
- ภาพที่ส่งให้ทีม: ค่าเริ่มต้นแสดงชื่อคณะทำงานและจำนวน/หัวข้อขาด ไม่แสดงรายบุคคลและค่าผลตรวจในภาพสรุป
